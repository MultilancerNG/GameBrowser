# GameBrowser 0.1.0-beta.85 — independent StakeMode upgrade

GameBrowser now opens its own standalone Live workspace and Settings. The approved dark interface is preserved; startup no longer loads the AliasMode host application or React dashboard.

- Restore Firefox Admin, Chromium Admin and mixed-engine followers, retaining the original 256-profile workspace.
- Keep assigned roles through selection, disconnects and profile reopening. Save and explicitly resume following plans after app restart; Stop following keeps browsers open.
- Follow supported clicks, text, scrolling and approved navigation/tab actions through one controller. Sensitive actions and uploads remain manual.
- Provide own TXT/CSV/JSON/XLSX transfers, recoverable Trash, identity/resource/bookmark settings, Cloud/Team and Local MCP screens.
- Restore TypeScript/Python StakeMode SDK compatibility on port 8080, plus GameBrowser aliases.
- Preserve groups, notes, bookmarks, proxies, local Chromium/Firefox add-ons, workflows, schedules and verified resource monitoring.
- Reuse existing GameBrowser data; support explicit staged full-state import from original StakeMode into an empty destination.
- Keep Cloud lifecycle, capture-before-close and encrypted pending saves separate from Local profiles. Use current permissions, bind queues to their original service and prepare the correct Cloud relay before first launch.
- Handle failed filesystem watchers without losing periodic session capture; refresh generated API metadata and Windows migration checks.

Publication requires full Windows source checks and fresh installed tests of both native following directions, navigation/tabs, add-ons, cookie isolation, workflows, saved-session desktop reopening, MCP discovery, shutdown and uninstall. Source, rendered UI and simulated-service evidence are tracked separately in the checklist. Actual installed UI screenshots accompany a passing release.

Full/offline and slim x64 installers include SHA-256 checksums. Live Cloud and remote MCP need a compatible service and remain unverified. Sites publication and gamebrowser.fiam.dev remain external setup. These are unsigned prerelease installers with manual installation; signed in-app updates are not enabled.
