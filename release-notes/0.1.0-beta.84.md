# GameBrowser 0.1.0-beta.84 — independent StakeMode upgrade

GameBrowser now starts its own standalone Live workspace and Settings. The approved dark interface is retained; desktop startup no longer loads the AliasMode host application or React dashboard.

- Restore Firefox Admin, Chromium Admin and mixed-engine followers, with up to 256 workspace profiles.
- Retain roles across selection, transport loss and browser reopening. Save and explicitly resume following plans after app restart; Stop following keeps browsers open.
- Mirror supported clicks, text, scrolling and approved navigation/tab actions through one controller. Sensitive actions and uploads remain manual.
- Provide own import/export, recoverable Trash, identity/resource/bookmark settings, optional Cloud/Team and Local MCP screens.
- Restore TypeScript/Python StakeMode SDK compatibility on loopback port 8080, with additive GameBrowser imports.
- Preserve groups, notes, bookmarks, proxies, Chromium/Firefox add-ons, workflows, schedules and verified resource monitoring.
- Keep the existing GameBrowser data directory and offer validated, explicit offline state import from the original StakeMode project.
- Keep Cloud browser capture/recovery, fresh permissions and encrypted queues separate from Local profiles. Bind pending saves to their original service and fence account-specific cache data. Prepare the correct Cloud relay before a profile's first launch.

The Windows publication gate requires a fresh installation, both native Admin/follower directions, navigation/tabs, add-ons, cookie isolation, workflows, saved-session reopening, MCP discovery, graceful shutdown and uninstall. Download promotion follows a passing gate. Source and simulated-service evidence is recorded separately in the checklist.

Full/offline and slim x64 installers include SHA-256 checksums. A compatible hosted Cloud service is separate; live Cloud, remote MCP, Sites publication and gamebrowser.fiam.dev remain unverified. Installers are unsigned prereleases with manual installation. Signed in-app updates are not enabled.
