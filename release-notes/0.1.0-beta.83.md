# GameBrowser 0.1.0-beta.83 — independent StakeMode upgrade

GameBrowser now starts its own standalone Live workspace and Settings, instead of loading the AliasMode host application. The approved dark interface is retained. Existing GameBrowser data stays in the same application directory; original StakeMode workspaces have an explicit, staged full-state import into an empty destination.

- Restore Firefox Admin, Chromium Admin and mixed-engine followers, with the original 256-profile workspace limit.
- Retain assignments across selection, transport loss and profile reopening. Save and explicitly resume following plans after a complete app restart; Stop following keeps browsers open.
- Mirror supported clicks, text, scrolling and approved navigation/tab actions through one relay controller. Sensitive actions and uploads remain manual.
- Add own profile import/export, recoverable Trash, identity/resource/bookmark settings, Cloud/Team and Local MCP screens without leaving the workspace.
- Restore original TypeScript/Python SDK compatibility on loopback port 8080 and additive GameBrowser imports.
- Preserve groups, notes, bookmarks, proxy management, local Chromium/Firefox add-ons, workflows, schedules and verified resource monitoring.
- Keep optional Cloud lifecycle and encrypted pending-session recovery separate from Local profiles, with fresh permissions and account/service cache fences.

The Windows publication gate requires a fresh installed application, both native Admin/follower directions, navigation and tabs, add-ons, independent cookies, workflows, saved-session desktop reopening, MCP discovery, graceful shutdown and uninstall. Public downloads are promoted only after this gate succeeds. Source and simulated-service evidence is recorded in the feature checklist.

Full/offline and slim x64 installers include SHA-256 checksums. A compatible hosted Cloud service is separate; live Cloud, remote MCP, Sites publication and gamebrowser.fiam.dev remain unverified. Installers are unsigned prereleases and require manual installation; this release does not enable signed in-app updates.
