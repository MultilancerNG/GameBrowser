The restored Live workspace and improved GameBrowser UI are included in this Windows installer.

- Live browser tiles and Full Admin View, with tabs, address bar, bookmarks and fullscreen controls.
- Chromium Admin with Chromium or Firefox followers, distinct role colors, fixed assignments and optional automatic Admin selection.
- Saved following groups with explicit resume after reopening the app. Stop following detaches synchronization while keeping the browsers open.
- Profile rearrangement, selected-first focus, import/export and recoverable Trash.
- Automatic or manual RAM soft targets, optional optimization and the Always show bookmarks preference. Resource preferences apply at the next fresh browser launch; RAM targets are not total-process caps.
- Local mode without an account. Team invitations, shared profile/group access, profile sync and remote MCP connectors require a separate compatible Cloud service; live Cloud service behavior has not been verified for this release.

Fixed Firefox Live workspace attachment on Windows by using the browser's effective content dimensions while preserving the saved profile identity.

Publication requires fresh installed Windows checks for real Firefox live frames, clicks, typing and tabs; mixed Chromium Admin / Firefox Follower actions; Stop keeping browsers alive; and following after Firefox closes and reopens.

Windows x64 beta. Full includes WebView2; slim downloads WebView2 when needed. Additional browser runtimes may download separately. Installers are unsigned; verify SHA256SUMS.txt.
