Tools for your profiles

These functions are available through the published beta 78 profile list and settings.

01

Local, without an account

Choose Local mode to keep profile data on your Windows device. You can create and run Local profiles without a Cloud account.

02

Separate sessions & identities

Each profile keeps its own saved browser identity, cookies and website storage. Reopening a profile preserves that profile’s settings and sessions.

03

Admin & Followers

A Chromium Admin can control Chromium or Firefox followers. Supported actions include clicks, typing, standard keys, checkbox/select changes, scrolling and website navigation. File uploads and operating-system dialogs are not replayed.

04

Groups that stay assigned

Selection alone leaves an active following group unchanged. Use Apply selection to change it, or Stop following to detach without closing browsers. Automatic Admin selection is optional and starts off.

05

Save, reopen, resume

Save following assignments for later. Open the required profiles, then explicitly resume the saved group. A saved group does not automatically launch browsers or serve as a browser-data backup.

06

Organize & move data

Use profile groups, drag order and recoverable bulk Trash. Import/export supported saved profile and cookie fields with TXT or XLSX; CSV carries account credentials. Exports are readable files, not complete browser-folder backups.

07

Choose your dimensions

Save desktop or mobile-sized screen dimensions with each profile. These are dimension settings; they do not emulate a mobile operating system or touch hardware.

08

Memory & bookmarks

Choose Auto or a manual RAM target, with optional memory optimization at the next fresh launch. Targets are soft, not total-process RAM caps. Set the bookmarks-bar preference while preserving existing bookmarks.

09

Cloud sharing & MCP

With a compatible Cloud service, verified accounts can use shared workspaces, portable profile sync and device controls. Use Settings → Team to invite members and share group or profile access.

Local MCP connects supported installed agents. Remote MCP connectors need that separate Cloud service and authorization.

Start with the profile list

Use these controls in beta 78. Live grid and Full Admin View belong to the next update.

  1. 01

    Choose your mode

    Install GameBrowser and choose Local for account-free use, or sign in to your compatible Cloud service.

  2. 02

    Open two or more profiles

    Create or import profiles. Open the browsers you want to use; at least one must be Chromium to act as Admin.

  3. 03

    Assign & start following

    Select at least two running profiles in the list. Choose a Chromium Admin and one or more followers, then select Start following.

  4. 04

    Work from the Admin

    Use supported actions in the Admin browser. Apply selection changes explicitly, or stop following when you want independent sessions.

A few things to know

Why is the download beta 78?

Beta 78 is the current published Windows installer. The Live workspace update has not passed final installed Windows validation yet, so the download remains beta 78.

Where are Live workspace and Full Admin View?

They are planned for the next update and are not in this download. In beta 78, use the existing profile list for following, selection, import/export and browser settings.

What changes when I select a follower?

With automatic following off, selecting a follower moves the selection without changing the active Admin or group. Apply selection changes explicitly. The optional automatic mode uses the newest selected Chromium profile as Admin; Firefox can follow.

Do I need Cloud for team access or agents?

Local mode and Local MCP need no Cloud account. Team invitations, shared profile/group access and remote connectors need a separate compatible Cloud service. This download page does not host browser sessions or provide that service.

Can I use browser extensions?

Beta 78 includes Manage extensions for Chromium profiles, with local uploads, supported Chrome Web Store installs and profile or group assignments. The Live workspace update adds expanded controls and Firefox add-on support.

Which Windows installer should I choose?

The full x64 installer includes WebView2. The slim installer downloads WebView2 when needed; additional browser runtimes may download separately. SHA-256 checksums are provided with the release files.
