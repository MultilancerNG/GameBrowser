Tools for your profiles

Use Live workspace for browser control, with Profiles and Settings available for profile management and Cloud access.

01

Local, separate sessions

Choose Local mode without an account. Each profile keeps its own saved browser identity, cookies and website storage on your device.

02

Live workspace & Full Admin View

See live browser frames in a grid, or expand a profile with Full view. Use tabs, the address bar, back/forward, reload, bookmarks and fullscreen. Followers require explicit manual control to browse independently.

03

Admin & Followers

A Chromium Admin can control Chromium or Firefox followers. Violet Admin and teal Follower borders keep roles clear. Supported clicks, typing, keys, checkbox/select changes, scrolling and navigation can follow the Admin within the configured websites. File uploads and operating-system dialogs are not replayed.

04

Selection without disconnecting

The selected profile appears first; drag profiles to save their order. Selection alone leaves following assignments intact. Use Apply selection to update the group. Auto-follow Admin selection is optional and starts off.

05

Save, reopen, resume

Save following assignments, open the required profiles and explicitly resume the saved group after restarting the app. Closed browsers retain their assignments while waiting to reopen. Stop following detaches control without closing browsers; past actions are not replayed.

06

Organize & move data

Use groups, tags, notes and recoverable bulk Trash. Import/export supported saved identity and session fields with TXT or XLSX; CSV carries account credentials. Full profile transfers and configuration-only templates are separate options.

07

Memory & bookmarks

Choose Auto or a manual RAM target and optional automatic memory optimization. Targets are soft, not total-process RAM caps. Set Always show the bookmarks bar while preserving existing bookmarks. Browser settings apply at the next fresh launch.

08

Task manager

Inspect live CPU and RAM readings for running profiles. Start, stop or explicitly force-close a profile’s browser, and choose resource alerts or other budget actions. Resource monitoring defaults to notification.

09

Extensions & add-ons

Manage local Chromium extensions and Firefox XPI add-ons, with profile or group assignments. Keep browser-wide extension permissions in mind when choosing which profiles receive an extension.

10

Routes & proxy library

Choose Direct, System or an explicit proxy route and save proxy endpoints for reuse. Network and extension assignment changes require a stopped profile. An operating-system VPN can still apply to Direct mode.

11

Local automation

Create local workflows, review outputs and schedule local runs while GameBrowser remains open. Browser actions use the profile’s current control permissions and configured website scope.

12

Cloud sharing & MCP

A compatible Cloud service enables verified-account access, shared workspaces, portable profile sync and device controls. Use Settings → Team to invite members and share group or profile access.

Local MCP connects supported installed agents. Remote connectors need that separate Cloud service and authorization.

Start in Live workspace

Choose your profiles, assign an Admin and keep control of when following changes.

  1. 01

    Choose your mode

    Install GameBrowser and choose Local for account-free use, or sign in to a compatible Cloud service. Live workspace opens after setup.

  2. 02

    Approve websites & open profiles

    Choose Configure scope and add the HTTPS websites you plan to use. Then use New profile or Import and start the browsers.

  3. 03

    Assign & start following

    Select two or more running profiles. Choose a Chromium Admin profile and select Start following. Leave Auto-follow Admin selection off to keep changes explicit.

  4. 04

    Work from the Admin

    Open Full Admin View for supported browser actions. Use Apply selection for group changes, Save session for later, or Stop following to detach control.

A few things to know

What is new in beta 82?

This release includes the improved Live workspace and Full Admin View, browser tabs and navigation, task manager, extension/add-on controls, proxy library and local workflows. If your beta 78 installation only shows the profile list, install this version to get the restored workspace. Profiles and Settings remain available for management.

What changes when I select a follower?

With automatic following off, selection brings that profile first without changing the active Admin or group. Use Apply selection to change assignments. Optional Auto-follow Admin selection uses the newest selected Chromium profile as Admin; Firefox can follow. Pause sync and manual takeover are explicit controls.

Will my following session resume automatically?

Save session stores the following assignments. After an app restart, open the required browser profiles and choose Resume. A saved group does not automatically launch browsers or act as a browser-data backup. Reopening a browser in an active group reconnects future actions without replaying past actions.

Can I use mobile-sized profiles?

Choose a phone, tablet or desktop preset, or save custom dimensions in Profile settings while the profile is stopped. These settings change dimensions without emulating a mobile operating system or touch hardware. Live views retain the browser’s actual aspect ratio.

Do I need Cloud for team access or agents?

Local mode and Local MCP need no Cloud account. Team invitations, shared group/profile access and remote connectors need a separate compatible Cloud service. This download page does not host browser sessions or provide that service.

What is included in a profile export?

TXT and XLSX preserve supported saved identity, cookie and session fields; CSV carries supported account credentials. These are readable files, not complete browser-folder backups. Configuration templates copy settings into fresh identities and do not include browser sessions or cookies.

Which Windows installer should I choose?

The full x64 installer includes WebView2. The slim installer downloads WebView2 when needed; additional browser runtimes may download separately. SHA-256 checksums are provided with the release files.
